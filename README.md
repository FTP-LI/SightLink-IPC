##  SightLink-IPC

## 一、背景

### 背景

本项目旨在设计一套基于 OpenIPC 的低延迟图传系统，项目整体分为天空端和接收机两个部分。天空端负责图像采集、视频编码和无线发送，接收机负责无线图传接收、链路调试和地面端视频输出。

天空端采用 `SSC338Q-IMX415-RTL8731BS` 硬件方案，接收机采用 `RTL8812AU` 无线模块方案。通过该项目，可以完成从 IPC 图像采集、视频编码、无线传输到地面端接收显示的完整链路验证。

### 技术定位

本项目定位为面向嵌入式视觉设备的 OpenIPC 图传系统设计与验证项目，重点围绕以下方向展开：

- 基于 SSC338Q 的 IPC 主控平台适配
- 基于 IMX415 的图像采集与画质调试
- 基于 RTL8731BS 的天空端无线发送链路
- 基于 RTL8812AU 的接收机无线接收链路
- 基于 OpenIPC 的视频编码、推流、启动配置和系统集成
- 低延迟、高稳定性图传链路的调试与测试

### 目标群体

本项目面向以下使用和开发群体：

- 嵌入式 Linux / OpenIPC 开发人员
- IPC 摄像头、图传系统和无线链路调试人员
- 无人机、机器人、远程巡检等场景下的视觉系统开发者
- 需要验证低延迟视频传输链路的硬件和系统工程人员

### 应用场景

本项目可应用于以下场景：

- 无人机低延迟视频图传
- 机器人第一视角视频回传
- 移动巡检设备远程视频监看
- 嵌入式 IPC 摄像头图传验证
- OpenIPC 固件适配、调试和二次开发
- 无线链路质量、码率、延迟和稳定性测试

### 整体思路

本项目按照“天空端采集编码、无线链路传输、接收机接收显示”的思路进行设计。

```text
天空端
IMX415 图像传感器
    |
    | MIPI CSI
    v
SSC338Q ISP / Encoder
    |
    | H.264 / H.265 Video Stream
    v
OpenIPC Runtime
    |
    | Wi-Fi / UDP / RTSP / WFB-ng
    v
RTL8731BS 无线发送
    |
    | 2.4 GHz / 5 GHz Wireless Link
    v
接收机
RTL8812AU 无线接收
    |
    v
地面站 / 播放器 / 视频处理端
```

系统设计重点包括：

- 天空端完成 OpenIPC 固件适配、IMX415 图像输入、SSC338Q 编码和 RTL8731BS 无线发送。
- 接收机完成 RTL8812AU 驱动适配、信道配置、监听模式验证和视频流接收。
- 通过 RTSP、UDP 或 WFB-ng 等方式验证端到端图传链路。
- 通过延迟、码率、丢包、RSSI 和断链恢复等指标评估系统稳定性。

## 二、项目构成

### 2.1 天空端板

天空端板采用 `SSC338Q-IMX415-RTL8731BS` 硬件方案，是整个图传系统的视频采集和发送端。

| 模块 | 型号 | 说明 |
| --- | --- | --- |
| 主控 SoC | SSC338Q | IPC 主控平台，负责系统运行、图像处理和视频编码 |
| 图像传感器 | IMX415 | Sony 4K CMOS 图像传感器，负责视频采集 |
| 无线模块 | RTL8731BS | Wi-Fi / 蓝牙无线通信模块，负责天空端网络连接和图传发送 |
| 固件生态 | OpenIPC | 开源 IPC 固件生态，负责系统基础能力、编码和推流配置 |

天空端主要工作内容：

- OpenIPC 固件启动、分区和系统服务验证
- IMX415 传感器识别、MIPI 输入和 ISP 参数调试
- H.264 / H.265 编码参数配置
- 分辨率、帧率、码率和 GOP 参数调优
- RTL8731BS 无线驱动加载、网卡枚举和联网能力验证
- 图传服务开机自启动和异常恢复配置

### 2.2 接收机

接收机采用 `RTL8812AU` USB 无线模块，是整个图传系统的地面接收端。

| 模块 | 型号 | 说明 |
| --- | --- | --- |
| 无线模块 | RTL8812AU | USB Wi-Fi 模块，用于无线图传接收、监听模式和链路测试 |
| 接收端系统 | Linux / 地面站设备 | 承载 RTL8812AU 驱动、视频接收服务、播放器或地面站软件 |

接收机主要工作内容：

- RTL8812AU 驱动安装和兼容性验证
- USB 网卡枚举、信道、带宽和功率配置
- Monitor 模式、注入能力和链路质量统计验证
- RTSP、UDP 或 WFB-ng 图传接收方式适配
- VLC、ffplay 或专用地面站的视频显示验证
- RSSI、丢包率、码率、端到端延迟和断链恢复测试

### 2.3 图传链路与软件配置

图传链路和软件配置贯穿天空端与接收机，是本项目的系统集成部分。

主要配置内容：

- OpenIPC 视频输入与编码配置
- RTSP / UDP / WFB-ng 推流与接收配置
- Wi-Fi STA / AP / Monitor 模式配置
- 天空端 RTL8731BS 网络与图传发送配置
- 接收机 RTL8812AU 信道、带宽、功率和天线配置
- 开机自启动服务配置
- 网络恢复、链路看门狗和异常重连策略

建议目录结构：

```text
SightLink-IPC/
├── air-unit/             # 天空端配置、脚本、固件说明和调试记录
├── receiver/             # 接收机配置、RTL8812AU 驱动说明和接收脚本
├── configs/              # 通用 OpenIPC、网络、视频编码等配置文件
├── docs/                 # 硬件连接、烧录、调试和测试文档
├── firmware/             # 固件镜像、补丁或构建说明
├── scripts/              # 部署、启动、测试和辅助脚本
├── tools/                # 地面站、接收端或链路调试工具
└── README.md
```

调试入口：

- 串口日志：观察天空端启动阶段、驱动加载、传感器识别和网络初始化
- `dmesg`：检查内核驱动、MIPI、ISP、Wi-Fi 模块状态
- `ifconfig` / `ip addr`：检查无线网卡是否正常枚举
- `iw` / `wpa_cli`：检查无线连接状态、信道和模式
- `lsusb`：检查 RTL8812AU 接收机模块是否被系统识别
- `airmon-ng` / `iw dev`：检查 RTL8812AU 是否可进入 Monitor 模式
- OpenIPC Web UI 或 SSH：调整图像、码率、分辨率和推流参数
- VLC、ffplay 或地面站软件：验证接收端视频流

## 三、总结

通过本项目，可以围绕 OpenIPC 图传系统积累以下代码和经验：

- SSC338Q 平台 OpenIPC 固件适配经验
- IMX415 图像传感器驱动、初始化和 ISP 调试经验
- RTL8731BS 天空端无线网络配置和图传发送经验
- RTL8812AU 接收机驱动、监听模式和链路测试经验
- RTSP、UDP、WFB-ng 等图传方式的配置和对比经验
- 嵌入式 Linux 开机自启动、网络恢复和链路看门狗配置经验
- 端到端延迟、码率、丢包率、RSSI 和稳定性测试方法
- 可复用的配置文件、启动脚本、测试脚本和调试文档

后续项目可继续沉淀天空端固件配置、接收机部署脚本、链路测试工具和完整的烧录调试文档，形成一套可复用的 OpenIPC 图传系统开发模板。
